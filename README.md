# BSL HTTP Server

## Project Description

This project is a low-level HTTP Web Server built from scratch using the
Bonezegei Scripting Language (BSL) and the BSL Socket Library.

The server listens on port 8080 and implements three types of responses:

- `/` - Home page
- `/about` - About page
- Any other route - 404 Not Found

## Technologies Used

- Bonezegei Scripting Language
- BSL Socket Library
- Visual Studio Code
- GitHub
